# Cod de Conduită / Code of Conduct

Acest proiect adoptă și respectă Codul de Conduită al comunității
[CivicTech România](https://github.com/civicnet/code-of-conduct).

Pe scurt: tratăm fiecare colaborator cu respect, indiferent de sex, orientare sexuală,
abilități, etnie, statut socio-economic sau religie; criticăm idei, nu oameni; și raportăm
comportamentele inacceptabile.

This project adopts the [CivicTech România Code of Conduct](https://github.com/civicnet/code-of-conduct).
In short: we treat every contributor with respect, we critique ideas rather than people,
and we report unacceptable behaviour.
